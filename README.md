## 繁殖牝馬の登録
馬DBの「＋繁殖牝馬」を押します。ゲーム内に元から存在する繁殖牝馬なら、「ゲーム内マスタから入力」で名前を検索して選択してください。基礎能力・ニトロに加え、ゲーム内15祖先データから父・父父・母父・父母父・母母父を補完します。女性祖先名そのものがゲームデータに含まれない欄は空欄のままでも問題ありません。

自家製牝馬は父・母を入力し、牧場DBまたは内蔵マスタに一致する祖先を順次引き継ぎます。自家製牝馬の面白・見事系統の完全な連鎖計算は次段階です。

## 配合理論
面白い配合は、3代前祖先8頭で異なる系統が7種類以上。見事な配合は、繁殖牝馬の面白用4系統と種牡馬の見事用4系統が、順序を問わず一致した場合に成立します。完璧な配合は面白＋見事の同時成立で、追加ボーナスはありません。

現在、デフォルト繁殖牝馬についてはゲーム内系統データから確定判定します。自家製繁殖牝馬は祖先データが十分に揃うまで推測判定しません。

## マスタ同期
`.github/workflows/sync-game-master.yml` が湯一路Switch版ダビスタページの一覧と配合ツールデータから、基礎能力・15祖先・面白／見事系統マスタを生成します。出典側で未判明の能力値は推測しません。

種牡馬・繁殖牝馬基礎データ: https://ds.yublog.com/
配合理論の参考: https://ds.yublog.com/theory.html
