# ダビスタSwitch 牧場DB

iPhone / Safari / ホーム画面追加を前提に、ダービースタリオン Switch の牧場データ、繁殖牝馬・種牡馬マスタ、配合候補、複数世代の配合設計を管理するWebアプリです。

## 現在の正式版

- Version: **v1.18.0**
- Build: **2026.09.21-43**
- 国内種牡馬: **176頭**
- 血統解析対象種牡馬: **214頭**（国内176＋外国38）
- デフォルト繁殖牝馬: **331頭**
- 繁殖能力既知: **298頭**
- 繁殖能力未判明: **33頭**（SP/ST/PW=0を低能力として扱わない）

## 主な機能

- 馬DB・レース印記録・バックアップJSON / 診断JSON
- Switch版デフォルト種牡馬・繁殖牝馬の基礎データと15祖先マスタ
- 面白・見事・完璧・凝った配合、危険配合、SP/ST/PWニトロ、各種クロスの判定
- ニトロは途中世代を単純加算せず、各世代の現在15祖先から再計算
- 自家製牝馬・自家製種牡馬を含む多世代血統の継承
- セリ繁殖牝馬からの直仔・2代・3代・4代配合比較
- 凱旋門賞、BC長期、繁殖牝馬再建、自家製種牡馬の目的別評価
- 母能力、血統上限、父実績・安定、距離根拠、クロス、配合理論を別軸で評価
- 未判明能力を0能力として順位付けしないmare-aware選抜
- iPhone向けの更新確認、Version/Build表示、モーダル操作・画面レイアウト調整

## 4代配合探索

2代目までは全探索です。3代目以降は計算量を抑えながら候補の取りこぼしを減らす条件付き探索を行います。

4代目は、代表4繁殖牝馬でwide480探索と比較検証した **compact bridge** を使用します。

- 一般6軸: 64件/軸
- SPクロス軸: 320件
- bridge D: 144件
- bridge A: 0件

これは全176⁴通りの完全探索ではありません。凱旋門、BC、繁殖再建、SP、SPクロス、強馬生産、ST、バランス、自家製種牡馬portfolioの各評価をwide480と比較し、代表検証で同等以上を維持した条件付き探索です。

## 繁殖牝馬の扱い

ゲーム内デフォルト繁殖牝馬はマスタから選択できます。既知能力298頭はSP/ST/PWを母能力として評価し、未判明33頭は能力値0として扱わず「未判明」として血統・ニトロ・配合理論を先に評価します。

高能力母は、すでに強い能力をさらに伸ばしたSP+ST合計だけで代重ねしません。母ごとの補強対象を見て、強みを維持しながら弱点軸が実質的に改善する場合に深い世代を比較します。

## 凱旋門賞・BCの評価

凱旋門向けではSP/ST、父実績、距離適性、長距離クロスなどを段階評価します。**2400m適性や実績Aは硬い必須条件ではありません。**

BC長期向けではSP17/ST5以上を一つの基準とし、多世代では途中または締めの有効SP補強経路を重視します。SPクロスや高ニトロは能力保証ではなく、血統上限・補強根拠として扱います。

## 配合理論

面白い配合、見事な配合、完璧な配合、凝った配合は共通配合エンジンで判定します。完璧は面白＋見事の同時成立で、独立した追加ボーナスとしては扱いません。

クロス効果は用途を分けて扱います。

- 短距離: スピードUP / SPニトロ+2・STニトロ-1
- 速力: スピードUP / SPニトロ+1
- パワー: パワーUP / PWニトロ+1
- 勝負根性: 勝負根性UP / STニトロ+1
- 長距離: スタミナUP / STニトロ+1

## マスタ同期

`.github/workflows/sync-game-master.yml` が湯一路Switch版ダビスタの公開データから、種牡馬・繁殖牝馬・15祖先・面白／見事系統などのマスタを同期します。出典側で未判明の繁殖能力は推測で補完しません。

データ同期後も、正式版へ反映する前に共通配合エンジンとセリ配合plannerの回帰テストを通す前提です。
