# ダビスタSwitch 牧場DB

iPhone / Safari / ホーム画面追加を前提に、ダービースタリオン Switch の牧場データ、レース印、配合候補を管理するWebアプリです。

## v1.4.0
- 馬DB・レース印記録・バランスブレイカー判定
- ホーム画面版向けの更新確認とVersion/Build表示
- バックアップJSON / 診断JSON
- 国内種牡馬マスタ（距離、実績・底力・安定、NSP/NST/NPW）
- 目的別の配合候補仮ランキング
  - 凱旋門・バランスブレイカー
  - イナリシャトル後継種牡馬
  - 血統・ニトロ再構築

## 配合判定の注意
現在のランキングは、距離適性・能力ランク・NSP/NST/NPWなどから作る透明なヒューリスティックです。4代血統に基づくクロス、凝った配合、見事、面白い、危険な配合はまだ未実装のため、最終的な配合判定ではありません。

種牡馬基礎データ: https://ds.yublog.com/stallion_list.php
配合理論の参考: https://ds.yublog.com/theory.html
