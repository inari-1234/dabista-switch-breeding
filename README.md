# ダビスタSwitch 牧場DB

iPhone / Safari を中心に、ダービースタリオン Switch の配合・競走馬データを蓄積して見返すためのWebアプリです。

## V1
- 馬DB（追加・編集・検索）
- イナリシャトルを基準種牡馬として初期登録
- 距離適性、実績・底力・安定、戦績、G1、メモ
- 2000〜2400mでの4番目/5番目の印を重視するバランスブレイカー評価方針
- 配合検討メモ
- JSONバックアップ/復元
- iPhone写真選択UI（画像解析は次版）

## 評価方針
Switch版のバランサーを前提に、2400m上限を単純に高評価しません。高SPを維持したままSTが残った外れ値を重視します。2000〜2400mでは4番目の印、5番目の総合印、実際のレース内容を合わせて評価します。
