# ダビスタSwitch 牧場DB

iPhone / Safari / ホーム画面追加を前提に、ダービースタリオン Switch の牧場データ、レース印、配合候補を管理するWebアプリです。

## v1.6.0
- 馬DB・レース印記録・バランスブレイカー判定
- ホーム画面版向けの更新確認とVersion/Build表示
- バックアップJSON / 診断JSON
- 国内種牡馬マスタ（距離、実績・底力・安定、NSP/NST/NPW）
- 目的別の配合候補仮ランキング
- 「＋繁殖牝馬」専用登録導線
- 登録区分（競走馬 / 繁殖牝馬 / 種牡馬候補 / 種牡馬）
- iPhoneでポップアップをスクロールした際に背景ページが一緒に動く現象を抑止
- 繁殖牝馬の血統入力補完
  - 父・母の候補を登録馬＋血統マスタから提示
  - 父が一致すれば父父・父母・父母父を補完
  - 母が登録済みなら母父・母母・母母父を補完
  - 登録済み牝馬を「母」として選択可能
  - イナリシャトル等の主要種牡馬は血統マスタから補完

## 繁殖牝馬の登録
馬DBの「＋繁殖牝馬」を押します。基本的には馬名・父・母から始めてください。父や母が登録済みデータ／血統マスタに一致すると「血統を自動補完」で関連欄を埋められます。母が牧場DBに登録済みなら「登録済みの母馬から選択」を使うと入力を大幅に省略できます。不明な欄は空欄のまま保存可能です。

## 配合判定の注意
現在のランキングは、距離適性・能力ランク・NSP/NST/NPWなどから作る透明なヒューリスティックです。面白い配合・見事な配合の正式判定には祖先の大系統データが必要なため、祖先名だけから推測しません。クロス、凝った配合、危険な配合もデータ確認後に段階的に実装します。

種牡馬基礎データ: https://ds.yublog.com/stallion_list.php
配合理論の参考: https://ds.yublog.com/theory.html
