# ダビスタSwitch 牧場DB

iPhone / Safari / ホーム画面追加を前提に、ダービースタリオン Switch の牧場データ、レース印、配合候補を管理するWebアプリです。

## v1.7.0
- 馬DB・レース印記録・バランスブレイカー判定
- ホーム画面版向けの更新確認とVersion/Build表示
- バックアップJSON / 診断JSON
- Switch版デフォルト国内種牡馬 176頭をマスタ化
  - 距離、成長、ダート、体質、気性、実績、底力、安定、NSP/NST/NPW等
- Switch版デフォルト繁殖牝馬 331頭をマスタ化
  - 価格、SP/ST/PW、ダート、NSP/NST/NPW等
- デフォルト繁殖牝馬を検索して、そのまま牧場DBへ読み込み可能
- 父・母などの入力候補にデフォルト種牡馬・繁殖牝馬名を追加
- デフォルト種牡馬を父に指定すると基礎能力を表示
- 詳細血統が確認済みの馬は、父父・父母・父母父／母父・母母・母母父を自動補完
- マスタは所有馬DBと分離し、必要な馬だけ取り込む設計
- iPhoneでポップアップをスクロールした際に背景ページが一緒に動く現象を抑止

## 繁殖牝馬の登録
馬DBの「＋繁殖牝馬」を押します。ゲーム内に元から存在する繁殖牝馬なら、登録画面の「ゲーム内マスタから入力」で馬名を検索して選択してください。名前、価格、SP/ST/PW、ダート、NSP/NST/NPWをマスタから引き継ぎます。父母の詳細血統がマスタにある場合は「血統を自動補完」で祖先欄も埋めます。自家製牝馬は従来どおり父・母を入力し、牧場DBまたは血統マスタに一致する祖先を自動補完します。

## マスタ同期
`.github/workflows/sync-game-master.yml` が湯一路Switch版ダビスタページの一覧から基礎マスタを生成します。国内種牡馬は海外・特殊種牡馬を除外し、デフォルト繁殖牝馬は一覧掲載分を保持します。出典側で未判明の能力値は推測せず、そのまま未判明として扱います。

## 配合判定の注意
現在のランキングは、距離適性・能力ランク・NSP/NST/NPWなどから作る透明なヒューリスティックです。面白い配合・見事な配合の正式判定には祖先の大系統データが必要なため、祖先名だけから推測しません。クロス、凝った配合、危険な配合もデータ確認後に段階的に実装します。

種牡馬・繁殖牝馬基礎データ: https://ds.yublog.com/
配合理論の参考: https://ds.yublog.com/theory.html
